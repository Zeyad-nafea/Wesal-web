# WESAL 

A clean, modern platform for discovering **Courses**, **Workshops**, and **Internships** — built with React and Tailwind CSS.

## What is WESAL?

WESAL connects learners and early-career professionals with educational and career opportunities. The platform keeps things simple: one search bar, clean filters, and everything you need — nothing you don't.

## Features (In Progress)

- **Universal Search** — search across courses, workshops, and internships from one place
- **Courses** — browse and filter by level and category
- **Workshops** — find hands-on, expert-led sessions
- **Internships** — explore openings with a quick apply flow
- **Dark Mode** — full light/dark theme support

## Tech Stack

- React
- Vite
- React Router
- Tailwind CSS
- Lucide React (icons)
